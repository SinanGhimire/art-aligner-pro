# Art Aligner Pro

Regenerate the accessories sheet properly — each cell containing only the headgear/mask on transparency (cleanest, fixes it permanently).

Auto-extract with per-cell alignment (shift each cell by its best-match offset, then diff against the plain cell and dilate the mask) and bake the result into a new PNG — feasible but lossy for on-face items like bandanas.
